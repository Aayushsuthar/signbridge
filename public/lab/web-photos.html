Clean web photos for every object

For each object in /models/objects-kb.json: searches Wikimedia Commons, embeds each photo with the app's CLIP, and keeps it only if CLIP ranks the object's own name in its top 5 among all objects (the CLIP-filtering used to clean web datasets like LAION). Photos in the evaluation categories are excluded. Rows { obj, file, rank, emb } go to ?post=.
