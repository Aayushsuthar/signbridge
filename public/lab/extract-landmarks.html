Hand landmark extraction

Turns an image-classification parquet (Hugging Face image + label columns) into MediaPipe hand landmarks for scripts/train-fingerspelling.mjs, using the same HandLandmarker as the app. Output rows: { label, pts: [[x,y,z]×21] } in square-pixel units.

Params: ?src=<parquet url>&labels=A,B,…&post=<collector url> (without post, a JSON file is offered for download at the end).
